# Evaluating the performance of kcat prediction tools and their impact on enzyme-constrained genome-scale metabolic models

This is a Master Thesis project conducted as part of the Master's in [Systems Biology & Bioinformatics](https://www.maastrichtuniversity.nl/education/master/programmes/systems-biology-and-bioinformatics) at Maastricht University. The project is carried out at the Reasearch Group for [Biochemical Network Analysis](https://chemnet.univie.ac.at/) in the Department of Analytical Chemistry at the University of Vienna.

## Project Information
This project is aimed to provide easy and automated installation for **kcat prediction models**. It also provides some benchmarking and visualization tools to compare the performance between the models.

## Requirements

Currently only linux systems with cuda enabled device (GPU) are supported.

## Setup

This project uses **Git submodules** to include external model repositories under the `models` directory.  
After cloning the repository, **you must initialize and update all submodules** before running any code.

### Submodule Setup
Clone with submodules:
```bash
git clone --recurse-submodules https://github.com/jlott/kcat-prediction-benchmarking.git
```
Or set up submodules after cloning:
```bash
git submodule update --init --recursive
```

### Environment Setup
Each model is run in a seperate conda environment to accomedate the specific dependencies needed. To automatically create and install all environment needed, run the bash script  `setup.sh` at the root of this repository (this might take some time):

```bash
./setup.sh
```
If the script can't find the `conda.sh` check the possible installation location for conda at the top of the script and add yours.

### Config Setup
The `config.json` found at the root of this repository can be used to customize some settings for this repository. Take a look at it __before__ running any models.

Additional files (like model weights etc.) that are needed by a model will be automatically downloaded when it is first used. These files will be placed under the **data_dir** directory. By default this will be `data` at the root of this project. The directory path can either be a local path from this repository or an absolute path. The directory itself (not any subdirectories) has to exist beforehand.

Configure the **device** that should be mainly used by the models, by default this will be the first gpu.

The **result_dir** specifies where the results generated by the `scripts` should be saved. Again this can be a local or an absolute path.

## Usage

You can find usage examples under the `scripts` directory. All scripts must be run in the **kcatbench** conda environment that got automatically created during setup.
